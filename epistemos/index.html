EPISTEMOS

Sovereign Context, Memory & Provenance Infrastructure for AI Agents.

Persistent temporal memory, explainable knowledge and decision lineage for any agent or runtime. Local-first, zero-egress, no mandatory LLM, zero runtime dependencies.

View on GitHub Read the Architecture

Why EPISTEMOS

Knowledge you can trust, through time.

Agent memory today couples knowledge to one LLM, vendor or vector database, mutates state in place so history is lost, severs provenance at ingest, and treats memory as a plain database rather than context replayed into a model. EPISTEMOS takes the opposite stance. Its source of truth is an append only, hash chained event ledger, and every fact knows when it was true, when it was believed, and where it came from. You keep your knowledge. It stays local, auditable and portable.

What it provides

Six capabilities, one sovereign layer.

🕓

Temporal memory

Bitemporal facts carry valid time (true in the world) and transaction time (believed by the system). Ask what you knew at any point, correct the past without losing it.

🕸️

Knowledge graph

Entities and relations are first class, queried through typed methods. No query language to inject into.

🔗

Provenance

A tamper evident, hash chained ledger. Every fact answers where did this come from, from source to derived fact.

⚖️

Decision lineage

Decisions record their evidence. Ask what led to this, and get the facts and sources that supported it.

🔍

Explainable retrieval

Every result reports its score components and a plain reason. No opaque similarity number.

🛡️

Multi tenant isolation

Tenant, agent and namespace on every read and write. Unknown scope, auth or integrity is refused, fail closed.

Works with any runtime

Model agnostic and agent agnostic.

Use EPISTEMOS from a Python SDK, a localhost REST API, or a hostile boundary MCP server. It is designed to integrate with governance and runtime systems as a consumer, never as an owner of the core.

NOMOS

Governance. Designed to integrate with, adapter ready. NOMOS decides what an agent may do, EPISTEMOS records what the system knows.

Hermes

Runtime and agents. Planned adapter. EPISTEMOS stays substitutable.

OpenClaw

External runtime. Planned adapter via SDK, REST or governed MCP.

MCP runtimes

A fixed, narrow tool allow list. No execute, eval or raw query tools. Identity is server side.

Claude / OpenAI agents

Any LLM based agent is a client. The core needs no model to run.

Custom agents

Own your memory behind a stable, documented API. Export everything as a versioned event log.

Integrations are planned or adapter ready. EPISTEMOS never grants a capability, it provides context, facts, history and evidence.

Temporal intelligence

What was true, what was believed, and what we believe now about the past.

Bitemporality keeps three questions separate, so knowledge is accountable and reconstructable.

valid time
What was true in the world, over an interval, independent of when the system learned it.
transaction time
What the system believed at a given moment. Corrections do not erase prior belief.
as of now, about then
What we believe today about a past instant, after later corrections. Reconstructable at any point.

Provenance

Every fact traces back to its source.

A hash chained ledger anchors a genealogy you can walk with a single call, explain(fact) and explain(decision).

Source→ Observation→ Fact→ Derived fact→ Decision

Security & sovereignty

Local first, by construction.

  • Local first. Runs from a single local file. No server required.
  • Zero egress by default. The core makes no network calls. Proven by test.
  • No mandatory LLM. A null model provider proves the core runs with no model at all.
  • Tenant and agent isolation. Fail closed on unknown scope, auth, source, schema or integrity.
  • Tamper evident ledger. A hash chain detects edits, reorders and truncation.
  • Zero runtime dependencies. Standard library only. No runtime supply chain.

Developer

Try it in a minute.

pip install -e ".[dev]"        # zero runtime deps
python examples/quickstart.py  # no model, no network

from epistemos import Engine, Principal
eng = Engine.open("knowledge.epistemos")   # one local file
ctx = Principal(tenant="acme", agent="claude", namespace="hr")
eng.assert_fact(ctx, subject="Alice", predicate="works_at",
                object="Acme", valid_from="2026-01-01")
eng.current(ctx, subject="Alice", predicate="works_at")   # "Acme"
eng.explain(ctx, fact_id)                                 # provenance genealogy
